🚀 Quick Start

Step 1: Open the Website

Simply open index.html in your web browser. No installation required!

Step 2: Explore the Homepage

The homepage showcases:

  • System overview and features
  • Problem statement and proposed solutions
  • Animated statistics
  • Team information

Step 3: Navigate to Different Modules

Use the navigation bar to access:

  • Dashboard: Real-time analytics and charts
  • Inventory: Product management with filters
  • POS: Point of sale system with cart
  • Customers: CRM with purchase history
  • Consignors: Payout tracking and calculations

💡 Key Features to Try

Dashboard Page

  • View interactive sales charts (7-day trend)
  • See category distribution pie chart
  • Check top-selling items
  • Review low stock alerts
  • Monitor recent transactions

Inventory Management

  • Search by SKU or item name
  • Filter by category, source, or stock level
  • Click "Add New Item" to see the intake form
  • Edit or delete items using action buttons
  • Export inventory data

Point of Sale (POS)

  • Click on products to add to cart
  • Adjust quantities using +/- buttons
  • Apply discounts
  • Select customer (optional)
  • Process cash or card payment
  • View transaction confirmation

Customer Management

  • Browse customer directory
  • Click a customer to view detailed profile
  • See purchase history and preferences
  • Filter by segment or preference
  • Send marketing emails
  • Add loyalty points

Consignor Management

  • View all active consignors
  • Check pending payouts
  • Click "View Details" to see consignment items
  • Process individual or batch payouts
  • Export consignor reports

🎯 System Benefits Demonstrated

Before (Current Problems)

  • ❌ Disconnected Square POS and Google Sheets
  • ❌ 2-3 days monthly for payout calculations
  • ❌ Only 70% inventory accuracy
  • ❌ No customer preference tracking
  • ❌ Generic marketing campaigns

After (Our Solution)

  • ✅ Unified platform - all data synchronized
  • ✅ Instant automated payout calculations
  • ✅ 99% inventory accuracy
  • ✅ Detailed customer insights and segmentation
  • ✅ Targeted, personalized marketing

🛠️ Technical Implementation
